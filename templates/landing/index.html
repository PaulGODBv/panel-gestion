Cómo se instala

Reta2 no está en Google Play: se instala desde el archivo. Android pedirá permiso una vez, y es normal.

  1. Descarga el archivo en el teléfono

    {% if hay_apk %} Pulsa descargar desde el propio móvil. Ocupa {{ apk_megas }} MB. {% else %} El archivo estará disponible aquí mismo en cuanto se publique la versión del piloto. {% endif %}

  2. Permite la instalación desde esta fuente

    Al abrirlo saldrá un aviso de que no se permiten instalaciones de fuentes desconocidas. Toca Ajustes y activa el permiso para el navegador o el gestor de archivos que estés usando. Es un permiso por aplicación, no un ajuste general del teléfono.

  3. Regístrate con tu correo institucional

    Hace falta una dirección @mail.udes.edu.co: es lo que permite relacionar tu avance con el programa académico en el que estás.
